# Sistema ImobiGestor

O ImobiGestor é um sistema SaaS para gestão de imóveis, vistorias e manutenções.

Ele foi criado para ajudar imobiliárias a controlar:

- vistorias de imóveis
- solicitações de manutenção
- orçamentos de prestadores
- execução de serviços
- custos e taxas administrativas

## Público alvo

Imobiliárias que administram locações.

## Problema resolvido

Hoje muitas imobiliárias controlam manutenção via:

- WhatsApp
- planilhas
- e-mails

O sistema centraliza todas essas informações.
